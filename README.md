# お絵描きツール v1.0.1

iPad(Apple Pencil)向けの、軽量なお絵描きWebアプリです。厚塗り向けに、機能をしぼっています。

## できること
- **ブラシ**: 鉛筆 / 消しゴム / ドット鉛筆 / ドット消しゴム(アンチエイリアスなし)。筆圧でサイズと濃さが変わります。サイズ・最小サイズ・不透明度・筆圧感度を調整できます。
- **カラー**: 色相リング + 彩度/明度。長押しでスポイト。
- **レイヤー**: 追加 / 削除 / 複製 / 下と結合 / 並び替え(右端の≡をドラッグ) / 表示切替 / アルファロック。キャンバスが大きいほど枚数は少なくなります(3〜5枚)。
- **元に戻す / やり直し**: 5回まで。
- **キャンバス**: 1:1 と 3:4 で計6サイズ(512〜2048px)。
- **書き出し**: PNG(透明) / JPG(白背景)。
- **自動保存**: 端末内(IndexedDB)に保存し、次回は続きから再開します。作品リストから過去の絵も開けます。
- **バックアップ**: 全作品を `.zip` で書き出し / 読み込み。
- ウィンドウ(カラー・ブラシ・レイヤー)はドラッグで移動、右下のつまみで大きさ変更。配置と設定は記憶されます。

## 操作(指はキャンバスに描きません)
| 操作 | 動作 |
|---|---|
| Pencil / マウス | 描く |
| 2本指ドラッグ / ピンチ | 移動 / 拡大縮小 |
| 2本指タップ | 元に戻す |
| 3本指タップ | やり直す |
| 動かさず長押し | スポイト |

## 公開のしかた(GitHub Pages)
1. このフォルダの中身をそのままリポジトリにアップロードします。
2. リポジトリの **Settings → Pages** で、Source を `Deploy from a branch`、Branch を `main` / `/ (root)` にします。
3. 数分後に表示される `https://<ユーザー名>.github.io/<リポジトリ名>/` をiPadのSafariで開きます。
4. 共有ボタン → **ホーム画面に追加** すると、アプリのように全画面で起動し、一度開いたあとはオフラインでも使えます。

## 保存について(大事)
- 作品はブラウザの保存領域に入ります。iOSは、長く使わないサイトのデータを消すことがあります。**ときどき「作品」→「バックアップ」で .zip を書き出し、ファイルAppに置いてください。**
- 書き出し(PNG/JPG/zip)は、iPadでは共有シートが開きます。「"ファイル"に保存」や「画像を保存」を選んでください。
- 保存データはサイトのURLごとに別です。公開先のURLを変えると、前の作品は見えなくなります(バックアップから戻せます)。

## ファイル
- `index.html` … アプリ本体(1ファイル)
- `sw.js` / `manifest.webmanifest` / `icons/` … オフライン・ホーム画面用

## 既知の制限
- ブラシカーソル(筆先の輪郭表示)はありません。
- 元に戻す履歴は保存されません(再開後はゼロから)。
- Apple Pencilのホバーは未対応です。
